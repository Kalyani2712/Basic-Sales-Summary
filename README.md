# Sales Data Analysis Script

This project includes a Python script to analyze sales data stored in a SQLite database (`sales_data.db`) and visualize the results.

## 📁 Files Included
- `analyze_sales.py`: Python script for analyzing and visualizing sales data.
- `sales_data.db`: SQLite database containing sample sales records.
- `sales_summary.csv`: Exported summary of sales by product (generated after running the script).
- `revenue_by_product.png`: Bar chart showing revenue per product.
- `quantity_by_product.png`: Bar chart showing quantity sold per product.
- `revenue_share_pie.png`: Pie chart showing revenue share per product.

## 🛠 Requirements
- Python 3.x
- pandas
- matplotlib
